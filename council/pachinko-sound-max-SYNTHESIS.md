## 0. 結論(1段落)

方向は現行 v0.1.1068 の **ffmpeg aevalsrc 直接合成で正しい**(会議の「ffmpegでは倍音もADSRも作れない」批評は事実誤認 — §3.4で反駁)。足りないのは音そのものではなく **「パチンコの文法=保留→きゅいん→リーチ煽り→大当たり→払い出し」の物語弧を、ギフト梯子・マイルストーン梯子・コンボ昇格(effectDirector)に一対一で張ること**と、現行に無い **ジャラジャラ(払い出し)** と **リーチ煽り(未解決終止)** の2音種。全音源は自作合成=ライセンス完全クリーン、全て決定論(乱数ゼロ)、先頭レイヤーは常に t=0 開始+指数エンベロープ=アタック実質0ms(「タイミング遅い」の再発防止)、全effectに highpass≥700Hz(VOICEVOX帯域の保護)。

## 1. パチンコ音の文法マッピング

### 1.1 パチンコ音の文法(5要素)と音響的正体

| 文法 | 実機での役割 | 音響的正体 |
|---|---|---|
| 保留音(ポン/チン) | 入賞・玉が入った小さな快感 | 純音系ブリップ1〜2発。1.5〜2.5kHz、減衰急、**2発目が上の音程**(上昇=快) |
| きゅいん | 期待の点火。一番「パチンコらしい」音 | 上昇チャープ(0.3〜0.6秒で1.5〜2.5オクターブ)+トレモロ25〜35Hz |
| リーチ煽り | 緊張の持続。**解決しないで終わる** | 上昇音形の反復+加速感。終端にベルを置かない(未解決終止=次を待たせる) |
| 大当たり | 緊張の解放 | きゅいん→**ベルカスケード(明確な和音の階段)**で解決。C7-E7-G7-C8 のような長三和音アルペジオ |
| 払い出しジャラジャラ | 報酬の物量感 | 高域金属打撃の高速乱打(20〜35打/秒)。乱雑さが物量を意味する |

### 1.2 イベント→文法の割り当て(確定案)

| イベント | 音種キー(player既存) | 文法 | 長さ | 設計意図 |
|---|---|---|---|---|
| ギフト小 | `gift_small` | 保留音(チン・チン2連) | 0.32s | 邪魔しない快感。2発目が上=ミニ上昇 |
| ギフト中 | `gift_medium` | きゅいん短+終端チン | 0.62s | 「きゅいん」をここに置く=一番頻度の高い中帯で一番パチンコらしい音が鳴る |
| ギフト大 | `gift_large` | きゅいーん強+チン2連 | 0.95s | 中との差=チャープが低くから始まり長い+ベル2連で強い解決 |
| ギフト特大 | `gift_mega` | 大当たり(きゅいん→カスケード4連→ジャラ尾) | 1.5s | フルコース。ジャラジャラの尾で「払い出された」感 |
| コメント節目soft(100/200) | `milestone_soft` | 保留音(ポポン上昇2連・チップ音色) | 0.30s | ギフト小と音色を変える(奇数倍音=PSGチップ風)ことで出所が聞き分けられる |
| コメント節目hard(500) | `milestone_hard` | リーチ煽り(3連上昇+スイープ・未解決) | 0.75s | 「まだ終わらないぞ」感。1000への期待を煽る |
| コメント節目jackpot(1000+) | `milestone_jackpot` | 大当たり+払い出し | 1.8s | 唯一の最長音。ジャラジャラ0.9秒つき |
| reach(Phase2メーター) | `reach` | リーチ煽りロング(未解決終止) | 1.0s | 盛り上がりメーター閾値越えで先鳴らし。解決は次のイベント音に委ねる |
| コンボ昇格 | (梯子の上位キーで置換) | 保留→きゅいん→リーチ→大当たりの弧そのもの | — | §1.3 |

### 1.3 決定論制約の中で最大の高揚感を出す核心

**コンボ昇格の梯子(effectDirector.directHit)を、そのままパチンコの物語弧にする。**

- `GIFT_TIER_LADDER` = small→medium→large→mega は、文法上 保留→きゅいん→リーチ級→大当たり と同型。つまり**30秒窓内の連続ギフトは、乱数ゼロで「リーチから大当たりへ向かう台」を自然に再現する**。実機の高揚感の本体は乱数ではなく「上昇の階段」なので、決定論でも成立する。
- 置換昇格(音を重ねない)は、実機の「保留音が鳴り止んでリーチ音に切り替わる」挙動そのもの。加算しないことがむしろパチンコ的に正しい。
- 各ティアの**先頭100msを音域で明確に差別化**する(small=2kHzチン単発 / medium=500Hzから上昇開始 / large=350Hzから / mega=300Hzから2オクターブ半)。昇格の瞬間に「開始音が一段低く・重くなった」と聞こえる=昇格が音だけで分かる。
- reach 音は「未解決終止」(終端ベル無し・導音で減衰)にする。解決は次に鳴る音(昇格後ティアや jackpot)が担う。これで**音楽理論上の緊張→解決が、600msガード・置換ルールと矛盾せずに**つながる。
- 600msガードとの整合: 昇格はキーが変わる(gift_medium→gift_large)ためガードに引っかからず即時に鳴る。同ティア連打だけが抑制される=設計通り。

### 1.4 VOICEVOX・配信音声との同居(帯域設計)

- 全effectに `highpass=f=700`(小物は800)。VOICEVOX の基本周波数帯(150〜400Hz)と胴体(〜700Hz)に一切エネルギーを置かない。
- 2〜5kHz は音声の子音明瞭帯と被るが、effectは**1.8秒以下の過渡音**なので瞬間マスキングで済む。会議素材(qwen)の「2-4kHzを避けよ」は持続音の話であり短SFXには過剰適用 — 逆にこの帯域こそ配信音声を**切り抜いて届く**帯域なので使う。
- 尾を引く音(jarajara, jackpot)のみ全体包絡 `exp(-1.8*t)` 級で確実に減衰させ、読み上げと重なる時間を最小化。

## 2. 全音源の ffmpeg 合成レシピ(完成形)

### 2.0 共通原則(会議素材の裏取り結果)

- **アタック10ms以内**(llama-70b案・妥当なので採用): `exp(-k*t)` エンベロープは t=0 で最大=アタック0ms。adelay を先頭レイヤーに掛けない。
- **倍音**: 「2〜3倍」は概ね妥当だが、ベル/コインには整数倍音でなく**非調和部分音 2.76倍**を混ぜると金属感が出る(実ベルの部分音比 1 : 2.0 : 2.76 : 5.4 に基づく)。チップ音(保留)は**奇数倍音 3倍**で矩形波感。
- **ピッチ上昇率**: llama-70bの「10〜20セント/秒」は**桁違いの誤り**(それでは1秒で半音の1/5)。実機きゅいんは **約1.5〜2.5オクターブ/0.3〜0.6秒 ≒ 5,000〜10,000セント/秒**。現行v0.1.1068の係数はこのレンジに入っており正しい。
- **終端の解決感**: aecho 55〜80ms/減衰0.3前後の2〜3タップ+終端ベル(長三和音の構成音)。リーチ系のみ意図的に外す。
- **決定論の変奏**: 変奏 n=1..3 は係数 `k = 1 + 0.06*(n-2)`(-6%/0/+6%)。現行方式を踏襲。乱数不使用。
- **ラウドネス**: `SYNTH_LOUDNORM = loudnorm=I=-6:TP=-0.3:LRA=9`(現行)を全合成音に適用。音量はplayer側 gift系1.0/他0.7 のまま。
- **実装地雷(重要)**: `mod(x,y)` のカンマは lavfi の filtergraph パーサでフィルタ区切りに誤解釈される。**`mod(t,P)` は使わず、カンマ無しの等価形 `(t-P*floor(t/P))` で書く**(下のジャラジャラは全てこの形)。式全体を `'...'` で囲む防御も可だが、floor形ならクォート不要で現行コードのスタイルに揃う。

以下、`synthToDest(inputs, filterComplex, dest, tmpDir)`(現行ヘルパそのまま)に渡す形で書く。`${...}` は JS テンプレートリテラル、`k` は変奏係数。

### 2.1 gift_small — 保留入賞「チン・チン」(0.32s)

コインベル2連。2発目が上の音程(C7→E7)。非調和部分音2.76倍で金属感を追加(現行との差分)。

```js
// small: コインベル2連(チン→チン↑)0.32秒。部分音 1 : 2.0 : 2.76
synthToDest(
  [
    `aevalsrc=(sin(2*PI*${2093 * k}*t)+0.5*sin(2*PI*${4186 * k}*t)+0.3*sin(2*PI*${5777 * k}*t))*exp(-25*t):s=44100:d=0.25`,
    `aevalsrc=(sin(2*PI*${2637 * k}*t)+0.5*sin(2*PI*${5274 * k}*t)+0.3*sin(2*PI*${7278 * k}*t))*exp(-25*t):s=44100:d=0.25`
  ],
  '[1:a]adelay=70|70[b];[0:a][b]amix=inputs=2:normalize=0:duration=longest,highpass=f=800,alimiter=limit=0.95[out]',
  join(TIERS_OUT_DIR, `gift-small-${n}.mp3`), tmpDir
);
```

### 2.4 ジャラジャラ(払い出し)— 新規音種・本設計の目玉

**素数系間隔の打撃列3系統**。各系統は「周期Pで指数エンベロープが打ち直されるコインベル」= `sin(2πFt) * exp(-K*(t - P*floor(t/P)))`。P を 73 / 97 / 113ms(素数ms)にすると3系統の重なりが約800msまで一度も同位相にならず、**完全決定論のまま乱雑=物量感**が出る。合計打撃密度 ≈ 32打/秒(実機の払い出し感のレンジ)。全体包絡 `exp(-1.8*t)` で収束。

```js
// ジャラジャラ式(部品として mega / milestone-jackpot から使う)。カンマ回避のため mod でなく floor 形。
const jara = (k, dur = 0.9) =>
  `aevalsrc=(0.55*(sin(2*PI*${2489 * k}*t)+0.5*sin(2*PI*${4978 * k}*t))*exp(-70*(t-0.073*floor(t/0.073)))` +
  `+0.45*(sin(2*PI*${3322 * k}*t)+0.5*sin(2*PI*${6644 * k}*t))*exp(-65*(t-0.097*floor(t/0.097)))` +
  `+0.4*(sin(2*PI*${4186 * k}*t)+0.4*sin(2*PI*${8372 * k}*t))*exp(-60*(t-0.113*floor(t/0.113))))` +
  `*exp(-1.8*t):s=44100:d=${dur}`;
```

- 周波数 2,489 / 3,322 / 4,186Hz(≈D#7/G#7/C8・お互い非整数比)+各2倍部分音 → 硬貨同士の非調和なぶつかり感。
- 打撃エンベロープ K=60〜70(1打の減衰≈15ms)=「ジャラ」の粒立ち。K を下げると「シャラシャラ」に寄る(調整ノブ)。
- 変奏は k による全体±6%に加え、**変奏2/3では P を 79/101/127ms・83/103/131ms(いずれも素数)に差し替え**るとリズムパターン自体が変わり、より台らしい。

```js
  join(TIERS_OUT_DIR, `milestone-jackpot-${n}.mp3`), tmpDir
);
```

### 2.9 reach — リーチ煽りロング(1.0s・変奏2本・未解決終止)

上昇チャープパルス3連(各0.22s・1段ずつ高い音域: 600→900 / 900→1350 / 1350→2025Hz=各完全5度上昇)+最後に**導音B6(1,976Hz)のビブラート保持がベル無しで減衰**=強い「次を待つ」感。player の `reach` キーは reach-1/2 の2変奏(既存配線)。変奏2は k=1.06 かつパルス間隔を240→200msに詰めた加速版。

```js
// reach: リーチ煽りロング(5度上昇パルス3連+導音保持・未解決)1.0秒
// n=1: k=1.0, gap=240 / n=2: k=1.06, gap=200 (加速変奏)
synthToDest(
  [
    `aevalsrc=(sin(2*PI*(${600 * k}*t+${682 * k}*t*t))+0.35*sin(4*PI*(${600 * k}*t+${682 * k}*t*t)))*exp(-6*t):s=44100:d=0.22`,
    `aevalsrc=(sin(2*PI*(${900 * k}*t+${1023 * k}*t*t))+0.35*sin(4*PI*(${900 * k}*t+${1023 * k}*t*t)))*exp(-6*t):s=44100:d=0.22`,
    `aevalsrc=(sin(2*PI*(${1350 * k}*t+${1534 * k}*t*t))+0.35*sin(4*PI*(${1350 * k}*t+${1534 * k}*t*t)))*exp(-6*t):s=44100:d=0.22`,
    `aevalsrc=sin(2*PI*${1976 * k}*t+6*sin(2*PI*6.5*t))*exp(-3.5*t):s=44100:d=0.45`
  ],
  `[1:a]adelay=${gap}|${gap}[b1];[2:a]adelay=${gap * 2}|${gap * 2}[b2];[3:a]adelay=${gap * 2 + 180}|${gap * 2 + 180}[b3];` +
    '[0:a][b1][b2][b3]amix=inputs=4:normalize=0:duration=longest,aecho=0.5:0.28:65:0.25,highpass=f=700,alimiter=limit=0.95[out]',
  join(TIERS_OUT_DIR, `reach-${n}.mp3`), tmpDir
);
```

(4本目の式はビブラート: 搬送 1,976Hz を 6.5Hz/±深さ6rad で位相変調=歌うような揺れ。カンマ無し。)

## 3. なぜ前回まで失敗したかの音響学的説明(次の判断基準)

パチンコ音の正体は「**電子純音系(サイン/矩形)・部分音が少ない・2〜5kHz・アタック0ms・明確な音程と上昇音形・規則的な反復/カスケード**」。歴代の失敗は全て、この正体のどれかを外している。

### 3.1 レジ音(OtoLogic)→「ギフトらしくない」
音色は近かった(ベル系)が**意味論が誤り**: レジ=「支払い・徴収」のアイコンで「もらった・報われた」ではない。単発固定音のため上昇音形(期待→解決の弧)も無い。教訓: **音色だけでなく音の物語(上昇・解決)が意味を作る**。

### 3.2 whoosh+impact+sparkle 3層ミックス→「しょぼい」
映画的SFXは**広帯域ノイズ基調・立ち上がり50〜200msのスウェル・中低域重心**。これはパチンコの正反対(純音・アタック0ms・高域)。さらにノイズ基調の音は配信音声(これも広帯域)に**マスキングされて埋もれる**。純音系ベルは配信音声のスペクトルの谷を突き抜けるので小音量でも通る。amix の normalize 既定減衰(1/N)も踏んだ(修正済みだが根本原因は音の系の選択ミス)。

### 3.3 ボディ増強・-9LUFS・着弾同期→「タイミング遅い」/ 短縮版→「パチンコっぽさが全然ない」
- 遅さの正体: 素材先頭の無音+スウェル型アタック+着弾待ち合わせ。**知覚上「即時」はアタック≦10ms**。音量や長さでは解決しない。
- 短縮の失敗が決定的な証拠: **長さはパチンコらしさの変数ではなかった**。0.45秒に切ってもノイズ基調・音程感無しのままなら「短いだけの映画SFX」。パチンコらしさは (a)純音系の音色 (b)チャープ=音程が走る (c)カスケード=音の階段 (d)アタック0ms の4点に宿る。v0.1.1068の合成転換はこの4点を初めて全部満たした=方向として正しい。

### 3.4 会議素材の裏取り結果(鵜呑み禁止分の裁定)
- **gpt-oss-120b「ffmpegでは倍音・ADSR・非線形ピッチが作れない」→ 事実誤認・棄却**。aevalsrc は任意の t の式(部分音の和・任意包絡・任意位相関数)を書ける。現行コードが既に `sin+0.5*sin(2f)` の倍音合成・`exp(-kt)` 包絡・二次チャープを実装している。外部DAW/SuperCollider導入の提案は本件の規模に対し過剰で、ビルド再現性(npm run sound:build 一発)も壊すため不採用。aecho が簡素なのは事実だが、1.8秒以下の短SFXに長残響は不要(むしろ配信と被る害)。
- **llama-3.3-70b「アタック10ms以内・倍音2-3倍・終端解決エコー100-200ms」→ 採用**(§2.0)。ただし同モデルの「ピッチ上昇10-20セント/秒」は桁違いの誤り、レシピ例(`noise(t)` 等)は aevalsrc に存在しない関数で全滅=数値は本設計で全面再導出済み。
- **qwen「音声帯域200-500Hz/2-4kHz回避」→ 半分採用**。低域回避は highpass で全面採用。2-4kHz回避は短SFXには不適用(§1.4)。
- **qwen「素数・フィボナッチ等の数列で乱数風の構造を作る」→ 採用**。ジャラジャラの素数間隔3系統(§2.4)として具体化した。
