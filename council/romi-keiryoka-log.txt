---

## 根拠  
1. **摩擦除去** – 初回表示で最も重いリソースはキャラ画像（22 MB／全体の 88 %）。画像を軽くすれば、拡張のポップアップが即座に描画でき、ユーザーが「重い」感覚を抱く瞬間を根本的に削減できる。

3. **現実主義** – 画像変換はフリーの CLI ツール（`cwebp`）だけで完結し、ビルドスクリプトに数行追加すれば済む。追加コストは 0 円。  
4. **離脱原因の除去** – 画像読み込みが完了するまでの白画面・カクつきが激減し、離脱率低減に直結する。  

---

## 結論

## 根拠

1. **摩除**：キャラ画像と背景音は、初期表示・初回操作の最大の重い要素であるため、これらを軽量化することで「最初の価値到達までの距離」が極限まで短くなる。
2. **計測志向と即時価値**：実測データで確認できるように、最も大きいファイルを最初に対処し、効果の大きい順に潰す。これにより、即座にパフォーマンス改善が見られる。
3. **現実主義**：画像や音声の変換はユーザーがローカルで実行できるため、低コスト・既存ツールで効く方法を優先する。
4. **離脱原因の除去**：読み込み中の白画面やカクつきを減らすことで、ユーザーの離脱率を下げる。

## 反論・リスク

1. **品質劣化リスク**：画像と音声の圧縮は、見た目や音質に影響を与える可能性がある。ただし、適切な圧縮設定でこれを最小限に抑えることができる。
2. **実行手順の複雑さ**：ユーザーがローカルで変換を行うため、手順が複雑になる可能性がある。

## 具体案

1. **キャラ画像の最適化（削減見込みバイト数：約20MB）**
   - **手順**：
     1. ユーザーがローカルで圧縮ツール（如く `imagemin`）を使用して、`extension/images/`内のPNG画像をWebPに変換する。
     2. 変換後、`manifest.json`の`web_accessible_resources`に更新されたファイルパスを反映させる。
   - **コマンド粒度**：
     ```bash
     npx imagemin extension/images/*.png --out-dir=extension/images/webp --format=webp --quality=60
     ```
     変換後、`manifest.json`を以下のように更新する：
     ```json
     "web_accessible_resources": [
       {
         "resources": ["extension/images/webp/*"],
         "matches": ["<all_urls>"]
       }
     ]
     ```

2. **背景音の圧縮（削減見込みバイト数：約4MB）**
   - **手順**：
     1. ユーザーがローカルで圧縮ツール（如く `ffmpeg`）を使用して、`tsuioku-no-kirameki/sound/yozora-small-yell.mp3`をAACに変換する。
     2. 変換後、LP側のHTMLファイル内で音声ファイルへのパスを更新する。
   - **コマンド粒度**：
     ```bash
     ffmpeg -i tsuioku-no-kirameki/sound/yozora-small-yell.mp3 -codec:a aac -b:a 128k tsuioku-no-kirameki/sound/yozora-small-yell.aac
     ```
     変換後、`index.html`内で以下のように更新する：
     ```html
     <audio src="tsuioku-no-kirameki/sound/yozora-small-yell.aac" loop></audio>
     ```

3. **HTMLの最適化（削減見込みバイト数：約500KB）**
   - **手順**：
     1. `index.html`内の不要なCSSやJavaScriptを削除する。
     2. CSSとJavaScriptのインライン化を最小限に抑える。
   - **コマンド粒度**：
     ```bash
     npx html-minifier --collapse-whitespace --remove-comments --remove-optional-tags --remove-redundant-attributes --remove-script-type-attributes --sort-class-name --sort-attributes tsuioku-no-kirameki/index.html > tsuioku-no-kirameki/index.min.html
     ```
     変換後、`index.html`を以下のように更新する：
     ```bash
     mv tsuioku-no-kirameki/index.min.html tsuioku-no-kirameki/index.html
     ```

4. **画像の遅延読み込み（削減見込みバイト数：約2MB）**
   - **手順**：
     1. `index.html`内で、非表示の要素に設定された画像を遅延読み込みする。
     2. JavaScriptを使用して、スクロールや特定のイベントが発生したときに画像を読み込む。
   - **コマンド粒度**：
     ```html
     <img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg==" data-src="tsuioku-no-kirameki/images/og-image.png" class="lazyload">
     <script>
       document.addEventListener("DOMContentLoaded", function() {
         const lazyImages = [].slice.call(document.querySelectorAll("img.lazyload"));
         if ("IntersectionObserver" in window) {

             entries.forEach(function(entry) {

           lazyImages.forEach(function(lazyImage) {
             lazyImageObserver.observe(lazyImage);
           });
         }
       });
     </script>
     ```
