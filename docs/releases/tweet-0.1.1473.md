## A. 長文版（そのまま貼れます）

```
【更新】君斗りんくの追憶のきらめき v0.1.1473 を公開しました。

先に正直に書きます。
今回、新しい機能はひとつも増えていません。

増えたのは「拡張が、キミに嘘をつかなくなったこと」だけです。
それでも、いちばん直したかったところでした。

━━━━━━━━━━━━━━━━━━━━

■ ことのはじまり

この拡張には「状態のお知らせ」という画面があります。
いま記録がどれだけ取れているか、どこかで詰まっていないか。
そういうことを、拡張が自分で測って教えてくれる画面です。

配信中に何かおかしいと感じたとき、
そこを見れば原因が分かる ── はずでした。

ところが、その画面がこんな数字を出していました。

　　取得率 501%

記録は、公式コメントの一部です。
一部が全体を超えることは、原理的にありえません。

━━━━━━━━━━━━━━━━━━━━

■ なぜ501%になったのか

原因を追いかけたら、こういうことでした。

　前の配信の記録件数（1,910件）を持ち越したまま、
　いまの配信の公式件数（381件）で割っていた。

1,910 ÷ 381 = 501%。
別の配信の分子を、別の配信の分母で割っていたのです。

ではなぜ持ち越していたのか。
そこには、ちゃんとした理由がありました。

記録の数字は、タブの状態によって一瞬だけ減って見えることがあります。
本当は減っていないのに、画面の上でだけ数字が下がる。
それを見たユーザーは「記録が消えた」と思ってしまう。

だから「前に出した数字より下げない」という仕組みを入れてありました。
これ自体は、正しい判断でした。

問題は、その仕組みが
【一瞬の揺れで減った】のと【配信が変わって減った】のを
区別していなかったことです。

前者は埋めていい。
後者は、埋めてはいけない。

配信が変わったら持ち越しを捨てるようにしました。
さらに、万一持ち越してしまっても、
100%を超えるときは数字を出さず「比較不能」とお伝えします。

ありえない数字を出すくらいなら、
「分かりません」と言うほうが誠実だからです。

━━━━━━━━━━━━━━━━━━━━

■ 「居ない犯人」を探させていた話

同じ画面に、こんな表示も出ていました。

　　残り384msは【囲んでいない処理】。
　　犯人はまだ名指しできません

拡張のどこかに、測れていない重い処理がある ──
そう読める表示です。

これも事実と違いました。

その384msは、パネルを開いた直後の
「待ち画面が出ている時間」でした。
その間、拡張はまだ何も始めていません。

探すべき犯人が、そもそも居なかったのです。

これはただの誤表示では済みません。
この表示を見た人は、居ない犯人を探しに行きます。
私自身、この表示に引っ張られて何日も別の場所を疑いました。

今回から【起動直後＝まだ始まっていません】と出します。
0%が正常だと、はっきり分かります。

もちろん、数秒たっても測れていなければ、
これまでどおり警告します。
本物の見落としは、見逃しません。

━━━━━━━━━━━━━━━━━━━━

■ 事実と違う警告を、やめました

もうひとつありました。

　　レポートが表示用の一部だけを集計している疑いがあります

保存されるレポートの件数が少ないときに出る警告です。

調べたところ、これも事実と違いました。
レポートは、記録を全件きちんと読んでいます。

ただし ──
「警告が鳴ったこと自体」は正しかったのです。
数字がおかしいのは本当で、
ただ拡張が指さした先が間違っていました。

なので、警告は消しませんでした。
消したのは【間違った名指し】のほうです。

今回からこう出ます。

　　集計対象が欠けている疑いがあります。
　　原因はまだ特定できていません。

分からないことを、分かったふりで書かない。
そう変えました。

━━━━━━━━━━━━━━━━━━━━

■ 3つとも、原因はおなじでした

ここが今回いちばんの発見です。

　　「本当に無い」のと「まだ分からない」のを、
　　同じ扱いにしていた。

・記録が0件 → 本当に0件なのか、まだ読み込んでいないだけなのか
・処理が0ms → 本当に何もしていないのか、まだ始まっていないのか
・数字が減った → 本当に減ったのか、配信が変わっただけなのか

どれも、前者なら伝えていい。
後者は、伝えてはいけない。まだ何も分かっていないのだから。

3つが同じ形だと分かったので、
今後まぎれ込まないように、検査で数を固定しました。

4件目・5件目が別の名前で現れても、
出荷前の検査が赤くなって止まります。

まだ直せていない箇所も2つ残っていますが、
それも「未修理」として名前つきで記録に残してあります。
忘れて放置される、ということが起きないようにしました。

━━━━━━━━━━━━━━━━━━━━

■ こういう地味な回について

新機能が増える回は、書いていて楽しいです。
今回はその逆で、増えたものがありません。

でも、状態のお知らせは
「何かおかしい」と思ったときに最初に見る画面です。

そこが嘘をついていたら、
直すべきでない場所を疑って時間を溶かすことになります。
実際、私がそうなっていました。

数字が信じられないお知らせは、無いのと同じです。

派手さはありませんが、
土台をまっすぐにする回だと思って出しました。

━━━━━━━━━━━━━━━━━━━━

記録はこのPCの中だけ。
広告も、トラッキングも、クラッシュレポートも入れていません。

スクロールで消えていく応援の言葉を、
なかったことにしないための拡張です。

これからも、静かに直していきます。

#ニコ生 #ニコニコ生放送 #コメントビューア #Chrome拡張
```
