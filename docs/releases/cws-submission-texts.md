## 2. 権限が必要な理由

### 2-1. storage が必要な理由

> 放送ごとの応援コメント、視聴者の出入り情報、ユーザー設定を chrome.storage.local に保存するために必要です。
>
> 本拡張機能の単一用途 (応援コメントのローカル記録・可視化) の中核そのものであり、この保存領域がないと「放送が終わったあとに振り返る」という機能自体が成立しません。
>
> 保存先は Chrome が拡張機能専用に確保するローカル領域で、外部サーバー・他の拡張機能・他サイトからは直接アクセスできません。拡張機能をアンインストールするとデータも完全に削除されます。
>
> 計測・分析・広告配信・クラウド同期のための保存には一切使用しません。

### 2-2. unlimitedStorage が必要な理由

> 毎日放送を追うユーザーや、長時間の放送を複数記録するユーザーのコメントログを失わせないために必要です。
>
> Chrome 標準の 5MB 制限では、1 放送あたり数百〜数千件のコメントが流れる実運用では短期間で上限に達してしまい、新しい放送のコメントが記録できなくなります。unlimitedStorage により、ユーザー自身の PC ディスク容量の範囲で安定して長期ログを保持できるようにしています。
>
> 保存データは chrome.storage.local 上のローカル保存で、容量拡張はユーザー本人の PC 内にとどまる話です。外部への送信は、ユーザーが「📱 スマホで見る」のスイッチを自分で ON にした場合に限られます (既定 OFF)。ネットワーク上の他者に影響は及びません。

### 2-3. scripting が必要な理由

> ニコニコ生放送のページ内で、拡張機能が提供する応援コメント可視化 UI (3 レーン表示、活発度ヒートマップ、Identicon、同接推定表示、コメント送信補助ウィンドウ等) を描画するために必要です。
>
> 具体的には、配信ページ上でコメント流を監視する content script と、ページ内描画コンテキストでフレーム計測やコメント DOM 取得を行うため chrome.scripting.executeScript を使います。また、ユーザーがポップアップから「コメント送信」「視聴ページの再読込」等の操作をした際に、watch ページ側のフォーム要素を呼び出すフォールバック経路でも使用します。
>
> 注入するコードはすべて拡張機能内に同梱された自前のスクリプトで、外部 URL からのコード取得や eval は行いません。実行対象は manifest の host_permissions に宣言された nicovideo.jp ドメインに限定されています。

### 2-4. downloads が必要な理由

> 放送終了後にユーザーが振り返るための HTML レポート、マーケ分析レポート (HTML)、コメントログの CSV、放送データの ZIP バックアップを、ユーザー自身の PC に保存させるために必要です。
>
> これらのファイルはすべて chrome.storage.local に既に保存されているユーザー本人の放送データから拡張機能内で生成され、ユーザーが画面上のダウンロードボタンを押した瞬間にのみ chrome.downloads.download が起動します。第三者サーバーから何かを取得するためには使用しません。
>
> 保存先は Chrome の標準ダウンロード設定で指定されたフォルダ (通常はユーザーの「ダウンロード」フォルダ) であり、ファイル名・内容はすべてユーザーの放送データから生成されます。自動・無断ダウンロードは発生しません。

### 2-5. alarms が必要な理由

> 長時間の生放送中、コメント記録データを 5 分ごとに IndexedDB へ自動バックアップするために必要です。
>
> ニコ生の長時間配信中にブラウザがクラッシュしたり、chrome.storage.local が一時的に書き込み失敗した場合でも、バックアップから直近 5 分前までのコメントを復元できるようにする目的です。
>
> setInterval ではなく chrome.alarms を使うのは、Manifest V3 の background service worker が一時停止された場合でも確実にバックアップが起動するためで、Chrome 公式の推奨パターンに従っています。
>
> 外部サーバーへの定期通信や通知の発火用途では一切使用しません。

### 2-6. tabs が必要な理由

> 拡張機能のポップアップから、現在ユーザーが開いているニコニコ生放送の配信タブを判別し、そのタブに対してメッセージ送信や必要に応じたリロード指示を出すために必要です。
>
> 具体的な用途:
> - 現在の配信タブを特定し、ポップアップ側で表示する応援コメント可視化の対象を決定する
> - ポップアップから配信タブへ「コメント送信」「視聴ページ再読込」「Speech 起動」等のメッセージを送る (chrome.tabs.sendMessage)
> - 視聴ページが応答不能になった場合のフォールバックとして該当タブを chrome.tabs.reload で再読込する
>
> URL 全件の取得や閲覧履歴・ブックマークの収集には使用しません。タブ ID と nicovideo.jp 配信ページの URL のみを使用し、外部送信もありません。

### 2-7. sidePanel が必要な理由

> Chrome の拡張機能アイコンをクリックした際に side panel が自動で開く挙動を「無効化」する目的で必要です。
>
> 本拡張機能はポップアップウィンドウ (popup.html) を独立ウィンドウとして開く UX を採用しているため、side panel が同時に開くと UI が二重表示になり利用者を混乱させます。これを避けるため、background service worker 起動時に chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: false }) を呼び出しています。
>
> side panel に何かを描画する目的でも、ユーザーデータの送信用途でも使用しません。

### 2-8. offscreen が必要な理由

> 記録した応援コメントの保存先である IndexedDB への書き込みを、常駐できる非表示ドキュメント (offscreen document) に集約するために必要です。
>
> Manifest V3 の background service worker は数分の待機で停止し、起動のたびにデータベースを開閉するため、コメント数が数万件ある放送を複数タブで開くと保存が直列化して詰まり「記録が増えない」状態になります。offscreen document に IndexedDB を開いたまま保持させることで、保存処理を 1 か所に集約し、視聴ページや service worker の停止に影響されず安定して追記できます。
>
> 用途は拡張機能内のローカル IndexedDB への書き込みのみで、音声・映像の取得や外部サーバーへの送信には一切使用しません。

### 2-8b. webNavigation が必要な理由

> ニコニコ生放送の配信ページが内部で複数のフレーム (iframe) に分かれているため、コメントを取りこぼさず記録するには「いま視聴中のタブにどのフレームがあるか」を把握する必要があり、そのために chrome.webNavigation.getAllFrames を使用します。
>
> 具体的には、ポップアップから配信タブへコメント可視化や送信補助の処理を行う際、対象タブのフレーム構成を取得し、コメントが流れる正しいフレームに対して処理を届けるために使っています。フレーム構成が分からないと、SPA 遷移や iframe 分割のある配信ページで「記録が始まらない・コメントが拾えない」状態になります。
>
> 参照対象は manifest の host_permissions に宣言された nicovideo.jp タブのフレーム情報に限られ、ユーザーの閲覧履歴の収集や他サイトのナビゲーション監視、外部サーバーへの送信には一切使用しません。

### 2-8c. ホスト権限 `http://127.0.0.1:50021/*` が必要な理由

> ユーザーが自分の PC にインストールした無料のローカル音声合成エンジン「VOICEVOX」（既定ポート 50021）と連携し、コメントビューアの読み上げ機能を提供するために必要です。
>
> 拡張はユーザーが読み上げを ON にしたときだけ、ローカルで起動中の VOICEVOX に対しテキストの音声合成をリクエストし、返ってきた音声をその場で再生します。VOICEVOX との通信はユーザー自身の端末内（127.0.0.1）で完結します。合成した音声を外部へ送るのは、利用者が「📱 スマホで見る」と、スマホ側の読み上げボタンの両方を自分で ON にした場合だけです（2-8d 参照）。VOICEVOX が起動していない場合、機能は自動的に無効のままです。

### 2-8d. ホスト権限 `https://app.tsuioku-no-kirameki.com/*` が必要な理由

> 利用者が状態画面のスイッチ「📱 スマホで見る」を自分で ON にした場合に限り、状態画面に表示されている内容のコピーを、当プロジェクトが運営するサーバー (app.tsuioku-no-kirameki.com) へ送り、利用者本人が自分のスマホで同じ画面を見られるようにするために必要です。
>
> ON にしたとき、サーバーがこの拡張専用の鍵 (ランダムな識別子) を発行します。氏名・メールアドレス・ニコニコのアカウント情報は使いません。サーバーに残るのは最新の 1 件だけで、24 時間で自動的に消えます。スイッチを OFF にすると送信を止め、サーバー上の内容と鍵の記録を削除します。
>
> 同じ宛先は、利用者がさらに自分で ON にした次の 2 つの機能にも使います (どちらも既定 OFF)。(1)「スマホで読み上げを聞く」: PC の VOICEVOX が作った読み上げ音声をスマホへ届けます (サーバーには最新 20 件まで・2 分で消えます)。(2)「✍️ スマホからコメントする」: スマホで書いたコメント本文をサーバー経由で受け取り (最長 1 分・受け取ると消えます)、PC で開いている放送タブのコメント欄から、そのブラウザでログインしているアカウントで投稿します。ニコニコのログイン情報は預かりません。(3)「👥 ファンにも公開」: 配信者などの利用者が自分で ON にすると、読むだけのファン用 URL を作り、その URL を開いた人も (1) 以前の「スマホで見る」と同じ内容を見られるようにします。サーバーに追加で保存する内容は無く、ファン用 URL からは投稿や PC の操作はできません。OFF にするとその URL は使えなくなります。
>
> スマホで画面を開いている間は、新しいコメント・ギフトを数秒ごとにまとめて同じサーバーへ送り、サーバーがリアルタイム配信サービス (Ably) を通してスマホへすぐ届けます。届ける内容は画面に表示されているものと同じ範囲で、Ably に残るのは配信のための短い時間 (通常 2 分) だけです。
>
> スイッチが OFF のあいだ、この宛先への通信は一切発生しません。広告配信・行動トラッキング・第三者への提供には使用しません。詳細はプライバシーポリシー §4-3 に記載しています。

### 2-8e. ホスト権限 `https://suggestqueries.google.com/*` が必要な理由

> 状態画面の「配信者の評判チェック」で、利用者が入力欄に入れて実行した (ボタンまたは Enter) 配信者名について、Google の検索候補 (サジェスト) を取得するために必要です。応援する配信者を安心して追えるよう、候補に注意すべき語が含まれていないかを 3 キャラが案内します。
>
> 送信されるのは利用者が入力した語句 (100 文字以内) のみで、記録したコメント・ユーザー ID・閲覧履歴は送信しません。利用者が実行操作をしたときだけ通信し、自動では発生しません。プライバシーポリシー §4-4 に記載しています。

### 2-9. ホスト権限 `https://*.nicovideo.jp/*` が必要な理由

> 本拡張機能は、ニコニコ生放送 (live.nicovideo.jp / live2.nicovideo.jp / www.nicovideo.jp 等) の配信ページ上でユーザー本人が視聴中の応援コメントをローカル記録・可視化することが単一用途であり、この用途を満たすためには nicovideo.jp ドメイン配下の watch ページに対して content script を注入し、コメント DOM・配信メタ情報 (タイトル・配信者 ID・同時接続数・コメント時刻等) を取得する必要があります。
>
> アクセス範囲はユーザーが通常ブラウザで見るのと同じ HTTPS リソースのみで、ログイン情報・課金情報・他サイトの閲覧履歴等の収集は行いません。取得した情報は既定では拡張機能を利用している本人のローカル PC (chrome.storage.local) にのみ保存されます。外部への送信は、ユーザーが「📱 スマホで見る」のスイッチを自分で ON にした場合に限られます (既定 OFF)。
>
> nicovideo.jp 以外のドメインでは content script は注入されず、本拡張機能は動作しません。

## 5. 提出時のチェックリスト

審査送信前に必ず確認する:

1. ✅ 「単一用途の説明」末尾の AI 連携記述が **「未実装」表現** になっているか
   （`privacy.html` §6 と整合）
2. ✅ 「データ使用 → 個人を特定できる情報」にチェックが入っているか
   （`privacy.html` §2 のユーザー ID 保存と整合）
3. ✅ scripting / downloads / alarms / tabs / webNavigation / sidePanel / offscreen と、4 つのホスト権限
   （nicovideo.jp / app.tsuioku-no-kirameki.com / suggestqueries.google.com / 127.0.0.1:50021）の理由欄が空欄でないか
4. ✅ アップロード ZIP は `python scripts/stage-submission.py <version>` で生成した
   `build/tsuioku-no-kirameki-X.X.X.zip` で、master の version と一致しているか
