# 開幕演出「ふってくる」— 再現プロトコル（フェーズ1）

調査・受け入れ時に次を記録する。H番号は `docs/codex-opening-celebration-investigation.md`（計画）と同一。

## 1-1. 環境

| 項目 | 記録 |
|------|------|
| 拡張バージョン | popup バッジ **0.1.575+** か（`chrome://extensions` → 再読み込み済みか） |
| 開き方 | **watch 埋め込みパネル**（`nl-inline-embed-watch`）か **ツールバー popup** か |
| 記録件数 | 例: 4384/4414 |
| 発火タイミング | パネル初回のみ / 閉じて再開でも / タブ切替後も |

## 1-2. 演出の種類（バナー文言 → 仮説）

| 文言の例 | 仮説ID |
|----------|--------|
| `アプリ記録 1,000 件達成！` 等 | **H1** コメント件数マイルストーン |
| `○○がギフト` + 三キャラズーム | **H2** ギフト Bahamut 過去コメ再生 |
| `○○pt広告しました` | **H3** ニコニ広告コメ再生 |
| `ギフト N 件目` | **H4** NDGR ギフト件数マイルストーン |
| `ニコニ広告 5,000pt 達成` 等 | **H5** 広告ptマイルストーン |
| 豪雨のみ・文言なし | **H6** 複数連続 or watch 中継 |

## 1-3. storage スナップショット

DevTools → 拡張 → `chrome.storage.local` で対象 `lv` のキーを **パネル開く前後**で比較:

- `KEY_SUPPORT_CELEBRATION_STATE`（`comment_1000`, `gift_10` 等）
- `nls_gift_events_<lv>` 件数

## 調査ビルド（フェーズ3）

コンソールで `globalThis.__NLS_CELEB_DEBUG__ = true` を設定してからパネルを開くと `[nls-celeb]` ログが出る（v0.1.575+）。

**合格**: 記録 2500+ 件・既視聴配信でパネル open 1 回あたり `[nls-celeb]` **0 件**。
