🗺️ 機能サイトマップ(何が・何をして・どのファイルか)

アプリの全機能を「分類 → 機能 → 役割 → 担当ファイル」で1枚に。AI も人間も、どの機能がどこにあるか一目で。 scripts/repo-tree-map.mjs の FEATURES/FEATURE_CATEGORY から自動生成(手編集しない・no CDN)。
全地図の入口: MAP.md ／ 全ファイル: code-tree.html ／ 逆引き索引: repo-tree-map.html ／ AI用テキスト: feature-sitemap.md。

scripts/impact-check.mjsdocs/feature-map/impact-map.json
読み方: 上=アプリ全体。下の各列=機能の分類(取得→記録→集計→表示・演出→読み上げ→レポート→診断)。 列の中のカード=1つの機能(太字=機能名・その下=何をするか・最下段=担当ファイル)。
赤いファイル=消えた/リネームされた担当(FEATURES 更新が必要)。 新機能を足したら FEATURES と FEATURE_CATEGORY に1行。npm run tree-map -- --check が腐りを検知。
