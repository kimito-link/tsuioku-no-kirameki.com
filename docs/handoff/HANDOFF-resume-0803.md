## ★このセッションで司令塔が誤診した回数: 6回(再発防止)

すべて **「観測しているものが本当に対象かを確認せず、理屈で埋めた」** が根。

1. 「鏡は56KBで全員載る」— `displaySrc` を空にして測っていた(実データの形でなかった)
2. 「広告段は strip されない」— `faceKey = uid || ...` の uid 優先を見落とし
3. 「`#N` が出るのは uid がある方」— 逆だった
4. 「画面が理屈と正反対」— 2つの別UIを混ぜて読んだ(実際は同一段)
5. 「ゆっくり顔が多すぎる=バグ」— blank.jpg と identicon の混同(4種類ある)
6. 「34倍の過剰」— 会場を開く前の値(22px)で測っていた。開くと50px=6.6倍

**断定前のチェックリスト**:
- [ ] 測っている入力は**実データと同じ形**か
- [ ] 「同じ段に見える」を**DOMの親子関係**で証明したか(スクショの近さで断定しない)
- [ ] 画像の同定は **currentSrc の先頭40文字**でしたか(目視で identicon/blank.jpg を区別しない)
- [ ] 優先順位のある式(`a || b`)は**左辺から**読んだか
- [ ] 「理論上あり得ない」が2つ同時に出たら、まず**観測系**を疑う
