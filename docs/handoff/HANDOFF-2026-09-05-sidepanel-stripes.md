## 0. 一次情報

- ユーザーの言葉: **「このまっくろくなるのなくしたい」**
- スクショ(2026-09-05 1:55): 右ペインが**縞状**に黒い。真っ黒ではない。

  サイドパネルで Chrome の暗い地が出ている」

## 1. ★Botの見立ては成立しない（実コードで確認）

### 事実1: サイドパネルに幕(cloak)は【無い】
`extension/sidepanel.html` の `cloak` 3件は **すべてコメント**。実コードに幕は無い。
```
:8   v0.1.1279 で幕(cloak)を足した版から黒が始まり…（経緯の記述）
:152 ■ これは【幕(cloak)ではない】——混同すると12版の失敗を繰り返す
:153 [[cloakNotForSidePanel]] が禁じたのは【中身を隠す幕】
```
★v0.1.1423 で **導入時(795c41b3・25行)の姿へ戻した**と明記。

### 事実2: 地の色は iframe より【先】に塗られている
`sidepanel.html:193` の body 構造（実物）:
```html
<div id="nl-underlay"></div>
<iframe title="ニコ生ログ" src="popup.html?inline=1&dock=sidepanel"></iframe>
```
`#nl-underlay`(`:169-183`): `position:absolute; inset:0; background-color:#fffaf2; z-index:0`

⟹ ★iframe が透明でも**背後にクリーム色がある**。Chrome の暗い地は出ない。
　　`:118-122` に実測記録あり —「透明にした状態で親の色を読むと rgb(255,250,242) が返った」

### 事実3: html にも地の色が二段構えで宣言済み
`sidepanel.html:1` と `popup.html:1` は**同値**（実物確認）:
```
style="color-scheme: light; background-color: #fffaf2;
       background-image: linear-gradient(160deg, #fffaf2, #eef8ff)"
```
★検査 `pageColorSchemeGate` / `colorSchemeMetaPresent` / `sidepanelBlackScreen` が機械照合。

⟹ ★**「色を宣言する方向」は既に全部やってある。** ここを触るのは13版目になる。

---

## 2. ★「縞」は過去84版が追っていた症状と【別】の可能性が高い

| 過去の症状 | 今回 |
|---|---|
| 一瞬の黒（約32ms・開いた直後） | ★**居座る**（スクショに写るほど） |
| 真っ黒（面で黒い） | ★**縞**（帯が交互） |
| about:blank の UA キャンバス | ★背後に underlay があるので出ないはず |

★`repeating-linear-gradient` 等の**縞を描くCSSは全ソースに0件**（grep 実測）。
⟹ ★縞は「模様」ではなく、**帯ごとに塗られたり塗られなかったりしている**状態。

★これは「色が黒い」問題ではなく、★**塗りが一部の帯に届いていない**問題として追うべき。

## 3. ★計器の穴（今回の調査で見つけた・これが次の一手）

`src/extension/sidepanel-entry.js:139`（実物）:
```js
const el = document.elementFromPoint(Math.floor(w / 2), Math.floor(h / 2));
```
★**中心1点しか見ていない。**

⟹ ★**縞は原理的に検出できない。** 中心が明るい帯に当たれば「黒くない」と判定する。
★ユーザーが「まっくろ」と言っているのに計器が緑を出す状態がありうる。
　（[[gate-watches-only-what-it-measures-2026-08-23]] と同型）

### ★次の一手（推奨・実装ゼロで判定できる）
1点→**縦に複数点サンプルする**（例: 高さを5等分した4点）。
- 全点が明るい → 縞は出ていない（別の面を見ている）
- ★点によって明暗が割れる → **縞を機械で捕まえた**＝再現条件を絞れる
★これは「直す」のではなく「**測れるようにする**」変更。体感の改善を主張しない。
