## 3. 残っている本物の問題

### (a) 状態速報の 🔴 が「まだ起きていないこと」を異常と言う ★次点で重要
実機で `popup 起動から 0.0秒後の値` を測り
「🔴 応援レーン描画が一度も呼ばれていません」と出していた。
しかし同じJSONに `laneTickProbe: runs=1 / lastRunAgoMs=3`＝**3ms前に動いている**。

★これが「押すたび全部緑にならない」の正体。判定側が
`⚠起動直後のため、ゼロや未観測でも正常です` という自分の但し書きを見ていない。
- 直す場所: `src/lib/storyUserLaneRenderProbe.js:256` の `started === 0` 分岐
- 既に `provisionalOnly` / `anonymousDominated` で同種のガードがある＝**同じ形で足せる**
- 入力に `popupBootAtIso` / `shadeAgeMs` があるので「起動から N ms 未満は判定しない」が書ける

### (b) タイルが 33枚→6枚 に減る
```
★タイルが減った直前の供給元: light_summary(暫定) 33枚→6枚
⚠ 縮小しているのにガードが素通り(provisional=false)=タイルが消える直接原因
```
計器が原因まで名指ししている。フラグ設定側を疑う。
