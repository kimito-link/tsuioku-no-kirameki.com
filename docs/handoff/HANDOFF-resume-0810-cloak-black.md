```
  / 中央の塗り主=iframe → rgb(255, 250, 242)
  / 窓0x0の継続=t=12〜12ms(524msまでに面積確定・1点)
```

### この行の読み方（重要）

| 項目 | 値 | 意味 |
|---|---|---|
| 窓0x0の継続 | **12ms・1点** | ★**窓のサイズは無罪**。人間に見えない。v0.1.1299 で疑ったのは誤り |
| 中央の塗り主 | iframe → `rgb(255,250,242)` | クリーム色は塗られている＝「誰も塗らない」型でもない |
| 原因 | **幕(cloak)が残っている** | ← **これが真犯人** |
| 検知時刻 | **t+60ms** | 出た直後の一瞬 |

### 調査の起点

- `extension/popup.html:1` に `data-nl-popup-primary-cloak="1"` が**静的に**書かれている
- CSS（`popup.html:1605-1609`）が `.nl-popup-primary { opacity: 0 }` にする
- 解除は JS の `revealPopupPrimaryOnce()`（`popup-entry.js:4052` 付近）と
  CSS フェイルセーフ（1500ms 後に 260ms かけて fade-in）
- 同じ速報の `loadShadeProbe` が **`shadePresent: true` / `shadeDone: true`**
  ＝ローディング幕は「完了」しているのに cloak は残っている、という状態

★**未確認**: cloak が残る条件（どの経路で `revealPopupPrimaryOnce` に到達しないか）。
　`popup 起動から 1.0 秒後` の撮影なので、CSS の 1500ms フェイルセーフ**前**の値である点に注意。
　「1.5秒待てば必ず消える」なら実害は「最初の1.5秒だけ薄い/黒い」になる。
　**次はこれを確かめる**（cloak が何msで消えるかを計器に出す or 実機で1.5秒後に取り直す）。
