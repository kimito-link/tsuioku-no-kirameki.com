# ノートPCで実行するチェック手順（2026-08-04）

デスクトップPCに持ち帰るための情報を集める手順です。
**ノートPC側にClaudeは不要**。画面を見てコピペ／メモするだけです。

所要 5〜10分。配信中（コメントが流れている状態）に行うのが理想です。

---

## 事前確認：拡張は最新か

ノートPCの拡張が古いと、以下の計器がそもそも入っていません。

1. Chromeで `chrome://extensions` を開く
2. 「君斗りんくの追憶のきらめき」のバージョンを見る
3. **メモする → 【A】バージョン = ______**

（デスクトップ側は v0.1.1245。大きく違えば、まずそこが原因かもしれません）

---

## 手順1：読み上げの数字を取る ★最重要

### 前提条件（これを満たさないと数字が出ません）

- **ニコ生の配信ページを開く**
- **コメビュ（会場モード）を開く** ← 必須。閉じていると読み上げの数字は出ません
- **読み上げをONにする**
- そのまま **1〜2分** 放置してコメントを流す（起動直後は全部ゼロです）

### 取得

1. 拡張のアイコンをクリック → **「状態」** タブを開く
2. ページ内に **「読み上げ追従」** と **「読み上げ漏れ」** の行があるので探す
3. **その2行に何と書いてあるかをメモする**

   - 【B】読み上げ追従 = ______
     （例：「追従中」「◯秒待ち」「◯秒沈黙」「合成◯◯ms」「OFF」「会場休止中」）
   - 【C】読み上げ漏れ = ______

4. 続けて、ページ下部の **「クリップボードへコピー」** ボタンを押す
   （見つからなければ「全部選択 (Ctrl+A→Ctrl+C)」でも可）
5. **【D】= コピーした内容そのまま**（メモ帳などに貼って持ち帰る）

---

## 手順2：VOICEVOXの状態を確認

1. ノートPCで **VOICEVOXが起動しているか** 確認
   - 【E】起動している / していない = ______

2. 起動しているなら、Chromeで次のURLを開く：

   http://127.0.0.1:50021/version

   - 【F】結果 = ______
     - 数字（例 `"0.24.1"`）が出た → 正常
     - 「接続できません」等 → **その画面が出るまでの体感時間**もメモ
       （**すぐ出た** / **数秒待たされた** ← ここが重要な手がかりです）

---

## 手順3：固まりの切り分け（「ページが応答しません」の件）

1. **読み上げをOFF**にする
2. そのまま普通に10分ほど使う
3. 【G】「ページが応答しません」が出るか = 出る / 出ない

**これが分かると原因が半分に絞れます。**
OFFで出なければ読み上げ関連、OFFでも出るなら別の原因です。

## 手順4：PCのスペック（任意・あれば助かります）

1. `Win + R` → `msinfo32` と入力 → Enter
2. 【H】プロセッサ = ______
3. 【I】実装メモリ(RAM) = ______

## デスクトップPCに持ち帰るもの

```
【A】拡張バージョン:
【B】読み上げ追従:
【C】読み上げ漏れ:
【D】状態速報コピー: (別途貼り付け)
【E】VOICEVOX起動:
【F】/version の結果と体感時間:
【G】読み上げOFFで固まるか:
【H】プロセッサ:
【I】RAM:
```

---

## 補足：なぜこれを聞くのか

現時点で**確定している**こと（デスクトップ側でコードを読んで計算済み）:

読み上げには「同時に抱えられる件数の上限」があり、**PCの速さで自動的に決まります**。

| 1件の処理時間 | 上限 |
|---|---|
| 300ms（速いPC） | 8件 |
| 1703ms | **3件** |
| 2500ms | **2件** |

計算式は `6000ms ÷ 1件の処理時間`。
枠が溢れると古い順に捨てられ、**そのコメントは読まれません**。

ノートPCで枠が2〜3件に落ちていれば、「たまにしか読まれない」の説明が付きます。
【B】【C】【D】でこれが**実測として裏付けられるか**を確かめたい、というのが趣旨です。

裏付けが取れれば打つ手が決まります（合成待ちが重いのか、再生が重いのか、
予算6秒の見直しが要るのか）。取れなければ見立てが外れなので、別を当たります。
