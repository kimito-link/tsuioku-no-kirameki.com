## 2. ★真因（確定済み・触ってよい場所/だめな場所）

### 構造が原因

v0.1.1275 でパネルを Side Panel へ移行したとき、
**`sidepanel.html` が `popup.html` を iframe で包む**構造になった。
直後から 1279→1283→1285→1289→1294→1298→1299 と**7版**「黒い」を直し続けている。

真因は **iframe の `about:blank` の隙間**
（[[about-blank-gap-is-the-black-2026-08-12]]）。
iframe の src が読み込まれる前の `about:blank` 文書には親の CSS が届かず、
`color-scheme: normal` ＝ OS がダークなら暗色になる。
★**要素の background は要素の地、中の文書のキャンバスはその上に合成**されるので、
外側から塗っても救えない。

### ★★触ってはいけない（7版ぶんの空振り記録）

- **幕(cloak)・シェードの「消し方」を増やす方向** … 7版やって症状は消えなかった
- **白0.2秒** … Chromium issue 40190899。**直せない。追わない**
  （[[sidepanel-white-flash-is-unfixable-2026-08-10]]）
- 窓0x0 / 幕の残留 / シェードの残留は**全て下流**。第一現象ではない
  （[[stalled-event-loop-masquerades-as-paint-bug-2026-08-12]]）

### ★本筋（未着手）

**iframe をやめて `sidepanel.html` に直接描く。**
影響が大きいので別タスクとして温存してきたが、
**ユーザーの体感が消えていない以上、ここに着手するのが正しい。**

## 5. 直近セッションで完了したもの（黒画面とは別件・参考）

`docs/handoff/HANDOFF-2026-08-17-comment-delay-investigation.md`。
