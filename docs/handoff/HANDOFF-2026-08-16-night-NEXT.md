## 3. 黒画面（残り2.5秒・設計上の上限）


★v1414 で「JS上限(2.5秒)を過ぎたら CSS が自力で薄れ始める」ようにした。
　いまの2.5秒は **設計通りの上限**。これ以上短くするなら
　`INLINE_SHADE_DATA_FALLBACK_MS`(popup-entry.js:18805) を下げる判断。

★**触ってはいけない**: 幕/シェードの「消し方」を増やす方向（7版空振り済）。
★白0.2秒は Chromium issue 40190899 で**直せない**。

### ★構造の話（未着手・本筋）
v0.1.1275 でパネルを Side Panel へ移行したとき、
`sidepanel.html` が `popup.html` を **iframe で包む**構造になった。
直後から 1279→1283→1285→1289→1294→1298→1299 と**7版**「黒い」を直し続けている。
＝ iframe の `about:blank` の隙間が黒の構造的な原因
　（[[about-blank-gap-is-the-black-2026-08-12]]）。
**本筋は「iframe をやめて sidepanel.html に直接描く」**。ただし影響が大きいので別タスク。
