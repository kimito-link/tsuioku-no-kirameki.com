### 退化① 署名に時刻を混ぜた（v1409で修理）

予算は「事故(80秒)を防ぐ上限」としては効いていたが
**「体感を守る上限」としては緩すぎた**。

## 3. 黒画面（★真因が確定した・次はここを直す）

### ★速報が犯人を名指しした（2026-08-16）
```json
"mainThreadBlocker": {
  "worstName": "(拡張の外)",
  "byName": { "(拡張の外)": { "count": 2, "ms": 1441, "worstMs": 853 } },
  "afterResumeCount": 2, "afterResumeMs": 1441
}
```
**止めているのはニコ生ページ側（拡張の外）。1441ms全部が可視復帰の直後。**

サイドパネル自己診断も一致:
```
中身が見えなかった合計 = 1222ms（幕660ms / シェード1222ms）主因=初回シェード
幕は t+935ms で解除 = CSS自動解除(400ms)より後 = ★JS解除が遅い
最大タイマー遅延 = 714ms ✅イベントループは健全
```

### ★結論: 幕が残るのは「JSが動けない」から
拡張の外(ニコ生ページ)が1441ms メインスレッドを止めている間、
幕を消すJSが動けない → 幕が935msまで残る。
＝ **幕の消し方をいじっても消えない**（7版空振りした理由がこれで確定）。

### 次に打つ手（この順で）
1. **幕・シェードの解除をJSに依存させない**
   CSSアニメーション完了だけで解除しきる（いまは JS 解除が遅れると935msまで残る）
2. **初回シェードの最低表示時間を短くする**（主因はシェード1222ms）
3. ★拡張の外は直せない。**待たされても隠さない**設計にする

★触ってはいけないもの: 白0.2秒（Chromium issue 40190899・直せない）
