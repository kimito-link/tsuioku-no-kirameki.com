読み方

● 各カード = トップレベルディレクトリ。タグ〔色 / コメント / レポート…〕がそのディレクトリの担当ドメイン。
● 赤枠 = 役割が未記入のディレクトリ。ROLES 辞書に1行足してから再生成する。
● ファイル件数は git 追跡分（生成物 build/ や .git 等は除外）。
