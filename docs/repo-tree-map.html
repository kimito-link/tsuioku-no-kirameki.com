読み方

● 上半分 = ディレクトリマップ（場所 → 役割）。各カード = トップレベルディレクトリ。タグ〔色 / コメント / レポート…〕が担当ドメイン。
● 下半分 = 機能逆引き（機能 → 担当ファイル）。「送信を司るのはどこ?」に一発で答える索引。
● 赤枠/赤パス = 役割未記入のディレクトリ or 消えた担当ファイル。辞書を直して再生成する。
● ファイル件数は git 追跡分（生成物 build/ や .git 等は除外）。
