この図の読み方

● 緑＝唯一の集約正本 userLaneCandidatesFromStorage()。popup も会場もここから同じデータを受け取る。
● 左＝popup列 / 右＝会場席。同じ集約を共有する「鏡映」設計（顔ぶれ一致が正）。
● 黄＝席資格の正本 venueParticipantKey()。userId があれば匿名でも席に座る。
● 赤＝来場者数(PV)。無言の通りすがり込みで userId が取れない→席に出せない→背景群衆 Canvas で密度として表現。

方針の変遷: 2026-06-13「匿名は座らせない」←撤回 → 2026-06-14「匿名も userId あれば着席」 → 2026-06-17「アクティブユーザー(アクションした人)は匿名/非匿名問わず全員着席」で確定。古い理解で誤らないこと。
