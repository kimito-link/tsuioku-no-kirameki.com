# reference: SocialXup の UIUX 知見(追憶の応援者パワー診断へ転用)

> 2026-06-14 ユーザー提供 https://socialxup.com を chrome-devtools-mcp で実機分析。
> X(Twitter)のフォロワー推移を可視化する登録不要・無料の分析ツール(12,000+アカウント監視)。
> 追憶(ニコ生コメント/視聴者の可視化・診断・ランキング)と問題領域が近い=直接転用できる UI が多い。
> 関連: [[reference_osint_strategy_socialxup_chikuran]]。

## 診断結果ページ(/tools/power/<id>)の構成=追憶の応援者パワー診断にそのまま効く

### ⭐1. 等級カード + スコアバー(一目で「今どこ・次どこ」)
- 左に**巨大な等級1文字「E」**(薄赤背景・角丸の大カード)+下に「これから」ラベル。
- 右に「**5** / 100」の大スコア + **E→D→C→B→A の横進捗バー**。現在地(E)を色付きで示し、
  上の等級が薄く並ぶ=「次に D を目指す」が直感で分かる。
- → 追憶版: 応援者パワーを A〜E + 0〜100 + 進捗バーで。「あと○で D」のような次目標も出せる。

### ⭐2. 色分けした数値カードのグリッド(6枚)
- フォロワー/フォロー中/投稿/いいね/メディア/リスト を**3列×2行のカード**に。
  各数字が**別々の色**(青/紫/ピンク/オレンジ/緑)+下に小さいグレーのラベル。視認性が高く即把握。
- → 追憶版: コメント数/ギフトpt/来場/同接/応援コメント/順位 等を同じ色分けカードグリッドで。

### ⭐3. シェアを最優先動線に(拡散の仕掛け)
- 診断カード直下に**「🐦 シェア」+「🖼 画像保存」**を大きく2ボタン横並び。
- さらに**「Xに投稿すると診断カードが自動で表示されます」**=OGP画像で診断結果が X 上に展開。
  → 追憶版: 診断/会場/コメビュ結果を「画像保存 + Xシェア」で。OGP は拡張だと難しいが、診断画像を
    canvas で生成して保存→手動シェアは可能。他AI知見の x.com/intent/post 統一とも合流。

### ⭐4. スコアの透明性(なぜそのスコアか説明)
- 「スコア算出について: ツイートデータなし(フォロワー数のみで簡易判定)」と**根拠を明記**。
- → 追憶版: 「この応援パワーは○○から算出(コメント数×ギフト×…)」と根拠を出すと信頼が上がる。
  星野ロミ流「無いものは出さない・分かることはセットで出す」とも一致。

### 5. 詳細分析は下に折りたたみ + バッジ
- 中央値インプレッション/エンゲージメント率/インプ効率 等に **C 等級バッジ**(小円)。
  概要は上・詳細は下、で情報量を段階化。
- → 追憶版: 応援者の詳細指標(発言密度/ギフト頻度/継続度)を等級バッジで。

### 6. ジャンル分類タグ
- 名前の下に「その他」「個人」等のカテゴリタグ。→ 追憶版: 配信者/応援者のタイプ分けタグ。

## レイアウト・トーンの学び(快適さ)
- 白基調・カードは薄影/薄ボーダー・角丸・余白広め=shadcn 風のフラットで読みやすい
  ([[reference_design_tokens_shadcn_socialxup]] と一致)。
- ヒーロー直下に大きな検索1個(迷わせない)。データは「開いた瞬間に出る」志向。
- 偏差値診断(全体/カテゴリ/同規模との比較)=「自分の位置」を見せる。追憶も「この配信の応援者は
  平均より上か」等の相対表示が刺さる。

## 採らないもの(追憶の方針)
- マネタイズ導線(¥650 でアカウント購入/「2009年作成16年もの垢が今買える」バナー)は追憶の非営利・
  健全方針と合わない=採らない。**レイアウトの快適さ・診断の見せ方・シェア動線だけ学ぶ**(MEMORY既出結論)。

## 追憶への適用優先(司令塔メモ)
1. 今すぐ効く=応援者パワー診断に「等級カード+進捗バー(A〜E・0〜100・次目標)」を入れる。
2. 数値カードグリッドの色分け統一。
3. 「画像保存+Xシェア」動線(診断/会場/コメビュ結果)。Xシェアは x.com/intent/post 統一。
4. スコア根拠の明記(透明性)。
