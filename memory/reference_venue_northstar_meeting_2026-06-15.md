# 会場 北極星会議 結論(2026-06-15) — 3キャラ必ず出す + コメント/音声リアルタイム

ユーザー(配信者)が定めた北極星: ①りんく・こん太・たぬ姉を**とにかく必ず出す**(消えず・邪魔せず) ②**コメント(吹き出し)と音声(読み上げ)がリアルタイムでちゃんと出る**。
会議=無料LLM(groq gpt-oss-120b/llama-3.3-70b・openrouter gpt-oss・local qwen3.5)。素材=.artifacts-ns-answers.json。

## ★3キャラの配置(全員一致)= 最前列中央→「配信画面のまわり」へ
- ユーザー実機「最前列中央に常駐は満員時に席/本家ギフト履歴と重なって邪魔」→案「配信画面のまわりに出す」。
- 会議結論: **左・右の縁(映像の左右)に固定。pointer-events:none で映像/クリックを邪魔しない。position:absolute(stageLayout基準) + vw/vh でリサイズ追従**。中央は空ける。サイズ控えめ(映像の~1.3%)。
- 3人が画面を囲んで「一緒に観てる」感=co-presence も上がる。満員でも閑散でも常に3人見える。

## ★コメント(吹き出し)をリアルタイムで取りこぼさず(一致)
- 主軸=storage.onChanged(イベント駆動)+ ハートビート poll を並走。poll 間隔 1.5秒→**0.8秒**に上げる。
- local qwen3.5 の鋭い指摘=seenKeys 判定でなく「**配列の増分を直接処理**」。maxEmit:8 の上限で洪水時に取りこぼす→バックログ(リングバッファ)で全部受け順次描画。
- 吹き出しは即出す(音を待たない・実装済み v0.1.745)。

## ★音声(読み上げ)をリアルタイムで(一致)
- VOICEVOX 起動を 0.5秒ごとに監視・失敗リトライ。洪水時は古い読み上げを捨て最新優先(FIFO上限)。
- 吹き出しと音声は非同期=吹き出し即・音声は順序保証で遅れてもOK。

## ⚠️司令塔が却下(裏取り)
- 「wss://live2.nicovideo.jp を WebSocket 直叩き」(gpt-oss/openrouter)→却下。背景の persist/NDGR の領域・「background.js/NDGR触らない」制約違反。会場は storage 経由が正本。
- 「location.reload() で設定反映」→乱暴で却下。

## 実装順(各段で test:cc 緑 + 実機確認・北極星優先)
1. **3キャラを配信画面の左右の縁へ移動**(ユーザー最大の不満「邪魔」を解消)。.nlsb-residents を seating 下端中央→stageLayout 基準で映像の左右に。
2. **コメントのリアルタイム強化**: SPEECH_INTERVAL_MS 1500→800、増分取得で取りこぼしゼロ、洪水バックログ。
3. (任意)音声キューの最新優先・VOICEVOX 監視強化。
