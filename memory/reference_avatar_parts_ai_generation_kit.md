# reference: 顔アバターパーツのイラストAI生成キット（B案・テイスト完全再現用）

> 2026-06-12 会議結論。コード生成（SVG）はv0.1.702で「かなり寄せた」が、手描きの揺らぎ・塗りの
> 質感まで完全再現するなら**イラスト特化AI（Gemini/ChatGPTの画像生成等）でパーツを1回だけ生成**
> →拡張内で決定論合成、が本命。コード系LLM（Codex等）は絵が苦手＝この用途には使わない。

## 使い方（ユーザー作業・1回だけ）

1. Gemini または ChatGPT を開き、**参照画像3枚を添付**:
   - `kimito-link/src/images/yukkuri-charactore-english/link/link-yukkuri-smile-mouth-closed.png`
   - `kimito-link/src/images/yukkuri-charactore-english/konta/kitsune-yukkuri-normal.png`
   - `kimito-link/src/images/yukkuri-charactore-english/tanunee/tanuki-yukkuri-normal-mouth-closed.png`
2. 下のプロンプトを貼って生成。**1回の依頼で1シートずつ**（髪→目→口の順）が安定。
3. 生成された画像を `memory/avatar-parts/` に保存して Claude Code に「組み込んで」と言う。

## プロンプト①: 髪パーツシート

```
添付した3枚は当方のオリジナルキャラクター（ゆっくり風デフォルメ）です。
この画風（太い黒アウトライン・アニメ塗り・ギザギザの毛先・天使の輪ハイライト）を
完全に再現して、「髪型カタログシート」を作ってください。

仕様:
- 正面向きの丸い頭部用の「髪のみ」（顔・目・口は描かない。頭の輪郭線もなし）
- 8種類の髪型を 4×2 のグリッドで1枚に（ボブ/外はねショート/ロング/ポニーテール/
  ツインテ風/マッシュ/センター分け/ウルフ）
- すべて男女どちらにも見える中性的なデザイン
- 髪色はすべて「グレースケール（白〜灰色）」で（後でプログラムで着色するため）
- 背景は完全透過（透過PNG）、各髪型は同じサイズ・同じ頭部位置を想定して揃える
- 解像度は1024x512以上
```

## プロンプト②: 表情パーツシート

```
同じ画風で「目と口のパーツシート」を作ってください。

仕様:
- 目: 6種類（ぱっちり/にこにこ閉じ目/ジト目/きらきら/驚き/眠そう）を横一列に。
  左右セットで、虹彩は茶色基調・白ハイライト2つ・太い黒アウトライン
- 口: 6種類（ω/にっこり/あーん/むっ/ぽかん/にやり）を横一列に
- 頬の赤らみ（楕円チーク）も1種類
- 背景は完全透過（透過PNG）、各パーツは等間隔グリッドで揃える
- 解像度は1024x512以上
```

## 受け取り後の組み込み設計（Claude Code 側・次セッション）

1. シートをパーツごとに切り出し（スプライト座標表を作る）
2. 拡張に `images/avatar-parts/` として同梱（グレースケール髪 + 表情）
3. `anonymousIdenticonDataUrl` を canvas 合成版に拡張:
   hash → 髪型×着色(hue/multiply)×目×口 を canvas で合成 → toDataURL キャッシュ
   （非同期になるため、現行SVG版を即時フォールバックとして残す二段構え）
4. 決定論（同じ人は同じ顔）はハッシュ層で不変
