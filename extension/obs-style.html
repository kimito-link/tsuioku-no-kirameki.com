Chrome で開く URL

この URL は、拡張が入っている Chrome で透過のコメント窓を開くためのものです。 OBS の「ブラウザ」ソースには貼れません。OBS の中のブラウザには拡張が入っておらず、 拡張のページも、このパソコンの中のコメントも読めません。 OBS では「ウィンドウキャプチャ」で、開いた透過窓を選んでください。 開くページは、いま見ている配信に合わせます。YouTube・Twitch・Kick・ふわっち・SHOWROOM・ミクチャ・TikTok は、そのコメントが入っているコメビュです。

コピーした URL は、コピーしたときの見た目で固定されます。透過窓を開くボタンの窓は、この画面の変更に追従します。
