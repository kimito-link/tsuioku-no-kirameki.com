## 8.5 ★「いろんなアクション」（2026-09-04 追記・YMM4の場面切り替えを見て）

★ユーザーの言葉:
> そこにこれがうごいて **ふわふわしながらしゃべる**
> **いろんなアクションもほしい**

★参照: YMM4(ゆっくりムービーメーカー)の場面切り替え解説動画
（「やや細かい横ブラインドが左右から」等のトランジション紹介）
⟹ ★**キャラが動くこと自体がコンテンツ**。ゆっくり実況の文法。

### ★既にある素材（実測）
**目3種 × 口2種 = 6パターン**が3キャラぶん揃っている:

| 目 | 口 |
|---|---|
| `normal`（通常） | `mouth-open`（開） |
| `blink`（まばたき） | `mouth-closed`（閉） |
| `half-eyes`（半目＝呆れ・ジト目） | |

★これは**ゆっくり実況の基本セットそのもの**:
- `normal` + 口パク交互 = ★**喋っている**
- `blink` = ★**まばたき**（生きている感じ）
- ★`half-eyes` = **呆れ・ジト目**＝勇者トロAIの「おまえさぁ・・」の顔

★つまり「忖度しない」を**絵で表現する手段が既にある**。

### ★今あるアニメーション（`charaLiveStage.js`）
- `nlcl-pop` … 出現時（160ms・下から浮き上がる）
- `nlcl-think` … 考え中（1.25s・3点リーダーが波打つ）
- ★`transform-origin: 50% 90%`「浮遊しても『立っている』感じが崩れない」＝ふわふわ設計済み
- `prefers-reduced-motion` 対応済み（`:233-234`）

### ★足すとしたら（未着手・アイデア段階）
★YMM4的な「場面切り替え」は**間を埋める**ことに直結する（アイキャッチの要素）。
- キャラの入退場（横から滑り込む・ふわっと消える）
- ★喋る番が回ったキャラだけ前に出る（誰が喋っているか分かる）
- 反応（頷く・跳ねる・のけぞる・首を振る）
- ★**沈黙が続いたときの手持ち無沙汰**（キャラ同士で顔を見合わせる 等）

★注意: `charaLiveStage.js:18` に既に掟がある —
「**transform は 1 本にまとめて書く**(translate/rotate/scale を別々に当てると上書き事故になる)」

## 10. ★「適度に」をどう作るか（設計の核心・未着手）

| 喋るべき | 黙るべき |
|---|---|
| ★無言が続いた（間が空いた） | ★配信者が喋っている最中 |
| コメントが来た | ★視聴者が盛り上がっている |
| 初コメの人が来た | 連続で喋った直後 |
| ギフトが来た | ★読み上げが動いている（声が重なる） |

★追憶には既に「読み上げ中は喋らない」ガードの前例がある（`venueSpeech` 周辺）。
