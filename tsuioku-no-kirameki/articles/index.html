発行者: Kimito-Link Project 運営: 君斗りんく

このページについて

本拡張機能の中で実装している技術的な手法・アルゴリズムを、論文や特許のように体系的にまとめて公開していくページです。実装は GitHub で MIT ライセンスのもと公開していますが、コードを読まなくても手法の本質が理解できるように、ここでは日本語で丁寧に解説します。

各記事に明記された公開日は、その手法が世の中に対して公知になった日付として位置づけています（防御的公開／defensive publication の趣旨）。同様の手法を別の主体が後から特許出願しても、これらの記事の公開日が先行技術として参照可能になることを意図しています。

    ライブ配信のコメント波形指紋によるリアルタイム類似配信検出

    配信中に流れるコメントの密度カーブを 16 次元の正規化ベクトルにし、過去配信の指紋とコサイン類似度で比較することで「形が似てる過去配信」を見つけ出す手法。配信時間や総コメ数が違っても比較できる軽量な fingerprinting アルゴリズム。

    ライブチャットの「コメ伝染／コメ被り」を sliding window で定量化する

    ライブチャットで起きる「コメ伝染」（30 秒以内に同じ語が複数ユーザーから飛ぶ連鎖）と「コメ被り瞬間」（5 秒以内の同期歓声）を、sliding window と正規化文字列マッチで軽量に検出するアルゴリズム。

    live streaming echo detection sliding window text normalization
  • 2026-05-01 公開
    ライブ配信の沈黙ゾーン検出と「沈黙の質」三段階分類

    コメント無し連続区間（沈黙ゾーン）を検出し、その直後の反応コメ数で「engaged（ガン見系）／departed（離脱系）／neutral（ふつう）」の 3 段階に質判定するアルゴリズム。沈黙を一律にネガティブ評価せず、配信者の話芸が効いた瞬間を検出できる。

    live streaming silence detection engagement

    個別視聴者の入退場ログが取れないライブ配信環境でも「初期にコメントしていたユーザーが配信終了時点でも何 % コメントしていたか」をセグメント別に計測する Kaplan-Meier 風の生存曲線手法。視聴維持率の代替指標として実装可能。

    live streaming retention Kaplan-Meier survival analysis

    Chrome 拡張機能から SPA の DOM ツリー内に inline panel を挿入する際、video 要素から祖先を辿って「視聴行（player + 公式コメ列）相当の矩形」を見つける rect スコアリング手法。eligibility（足切り）→ score（残った中の最良）の二段判定で、SPA の動的な DOM 変化に追従する。

    複数タブ間で chrome.storage.local を leased channel として使う prewarm coordinator

    Chrome 拡張機能で複数タブが同時に prewarm（事前ロード）を走らせて CPU を取り合う問題を、chrome.storage.local を leased channel として使う first-write-wins 方式で解決する手法。TTL fallback で停止タブの lease を横取りできる純粋関数設計。

    chrome extension multi-tab distributed coordination leased channel

    ライブチャットの定型反応を 4 カテゴリ（笑・命中・評価・状態宣言）に分類する辞書とトークナイザ

    「草」「www」「正解」「あ」「監視中」「ひっど」のような定型反応コメントを、笑反応・命中反応・評価反応・状態宣言の 4 カテゴリに辞書ベースで分類する手法。形態素解析や ML を使わず、視覚的同等性に基づく正規化と短語彙テーブルで配信中のリアルタイム集計を可能にする。
